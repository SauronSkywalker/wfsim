# Orvius

Chinese name: 灵枢

Glaive · Melee · Mastery Rank 5. 195 base damage (impact 39, puncture 9.75, slash 146.25), 18% crit chance, 2x crit multiplier, 18% status chance.

## Not modelled here

- One attack input's animation length is unpublished: the wiki gives each combo's total at 1.0x attack speed, so totals are exact and inputs are split evenly. This shifts a status tick by fractions of a second and changes no total.
- Power Spike's partial combo decay is a Warframe passive and is not modelled: the counter drops to zero when its timer runs out, so with that passive the number reads low.
- Not modelled: Throw, Throw Bounce Explosion, Throw Recall Explosion, Charged Throw, Charged Throw Bounce Explosion, Charged Throw Recall Explosion and Hover Attack. Of this weapon's attacks, only the swing, the slam and the heavy slam are.
- A glaive's heavy attack is a throw, which is not modelled, so there is no heavy mode and a Tennokai window converts nothing.
